HOW TO READ THIS
  * >=2 shared PRIVATE (non-hotspot) somatic variants with matching CCF = one neoplasm.
  * Shared hotspot(s) only = weak evidence; go to WES / methylation array / 9p21 breakpoint.
  * Zero shared variants with >=4 confident private variants in each = independent primaries,
    PROVIDED T2 purity is high enough that a clonal variant would have been seen
    (at purity 0.30 a clonal heterozygous variant is expected at VAF ~0.15).
  * GIS, TMB, MSI and CDKN2A ratio differences track purity, not biology; do not use them.
  * HLA type is germline; identical HLA is uninformative. HLA LOH (LOHHLA) can be subclonal.
  * Lineage call: SF-1 (ACC) vs WT1/D2-40/CK5-6/BAP1-loss (mesothelioma); shared CTNNB1/ZNRF3
    favours ACC, shared BAP1/NF2 favours mesothelioma. Methylation classifier settles lineage.
